# Presentation contracts

Use Barlow Condensed for short display headings and Inter for player identity, prose and labels. Long player/venue strings wrap at words. Preserve existing original assets and embedded-font licensing. Fonts must retain genuine tabular substitutions.

Rating bands in the current presentation are emitted by GCC8.ratingBand: elite90, strong82, sound73, thin64, weak below. Card and metric styling reads data-tier on gccuiRating. The superseded data-rating-tier card attribute and star/core vocabulary are removed. Zero is rendered as weak for band styling; legacy text may say Not set where a value is absent. Chemistry has its own unrelated Settled/Building/New side/Unsettled vocabulary.

Finals wrappers expose gccuiTitleWon or gccuiTitleDone only after stage done, using the actual champion. CSS is not permitted to infer sporting events from numeric text. Confetti and looping foil/title/moment animations remain disabled pending motion/performance review.

Current maintenance debt: baseline, decision, compatibility and broadcast styles still coexist. Consolidate by component with computed-style and screenshot comparison. Do not claim this debt is resolved by this document.
