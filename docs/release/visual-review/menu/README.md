# GCC v116 menu visual review

Cross-reference source: Claude's uploaded v115 HTML prototype and gcc_menu_flat_dense_prototype.css. The HTML contains the earlier card-based treatment; the standalone CSS is the later flat-dense direction used for this review.

The screenshots are rendered from a disposable v116 menu candidate. It starts from the already accepted finals candidate and replaces only the existing guide CSS owner inside the existing decision-ui.css style block. No new stylesheet or JavaScript is added.

Design changes under review:
- Two guide columns from 860px; one column below.
- Flat guide rows and rule disclosures with thin dividers.
- Circular numbered markers, matching v116's actual h3 guide headings.
- Story cards remain a single narrative column.
- Charcoal modal surface and readable story-card text.
- Footer links retain 44px minimum control height.

The 18 screenshots cover all three guide pages at 320, 390, 768, 1024 and 1440px, plus each expanded rule group on mobile.

This is a QA review candidate only. It is not the frozen v116 playable release and has not been promoted.
