Capture the current game

Open the latest game in its own browser window. Click Start capture and select that game window in the browser’s sharing chooser. Move through Home, Season, Squad/XI, Matchday, Scorecard and the offseason screens you want reviewed. Hold each screen for about five seconds.

This collects one image every four seconds, up to 90 images. Everything stays on your computer until you choose to send the downloaded ZIP.

Checking screen capture support…

The game is not loaded or changed by this tool. Select only the window you want included. The ZIP contains the captured pixels and capture times; it does not verify the game version.
