# Career experience verification

Read `docs/GCC_V8_CAREER_EXPERIENCE_REVIEW.md` for scope and remaining risks.

From the repository root:

```bash
python qa/completion/build_candidate.py
node qa/career-experience/behaviour.mjs
node qa/career-experience/native.cjs
node qa/career-experience/scout.cjs
node qa/career-experience/entry-render.cjs
node qa/completion/offseason-browser.cjs
node qa/cricket-detail/focused.mjs
node qa/career-experience/growth-probe.mjs
```

Native scripts require Playwright and the local Chromium test runtime at `/tmp/gcc-chromium`. The behaviour/native/scout checks use the actual completed-2010 checkpoint generated by `qa/structural-risk/career-run.mjs`. Generate that career as described in its README. No checkpoint saves are added to the product or committed here.

Fresh full careers were run with `GCC8_TEST_BUILD=game/gcc_v8_product_candidate.html`, `GCC8_TEST_SEED=202` or `303`, and separate `GCC8_TEST_REPORT_DIR` directories through `qa/structural-risk/career-run.mjs`. They started before final scout-only markup/contrast refinements. Their summaries are `career-202.json` and `career-303.json`; they are not exact-final-artifact visual tests.

For the exact final artifact continuation:

```bash
GCC8_TEST_BUILD=game/gcc_v8_product_candidate.html GCC8_TEST_REPORT_DIR=qa/career-experience/final-resume GCC8_RESUME_FIXTURE=qa/career-experience/world-202/checkpoint-2020.json node qa/career-experience/resume.mjs
```

`final-resume.json` explicitly distinguishes six exercised seasons from the nineteen-season archived history. It includes the final artifact hash. `growth-probe.json` is twelve independent career universes without matches or team selection, not twelve full UI careers. Rating calibration is unchanged and remains open.

`regressions.json`, `annual-render.json`, `entry-browser.json`, `scout.json` and `native.json` describe final-artifact checks. The entry renderer treats the compact header's intentional single-line ellipsis separately: it verifies the full DOM name, clipping style and line height instead of treating clipped glyph ranges as visible overflow. No other text-overflow findings are suppressed. Contrast scans do not certify image/gradient backdrops.
