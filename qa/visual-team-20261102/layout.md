# GCC layout audit — read-only findings

Scope: `decision-ui.css`, `decision-ui.js`, `career.js`, `screens.js`. No browser was accessed. Current Build 33 captures were not present when reviewed. The only inspected raster was `qa/management-20261101/browser-build32-offseason.png` (1135 × 657), which is explicitly older Build 32 evidence; do not treat its dressing-room placement as a current Build 33 defect.

1. **Draft cards get narrower immediately above the 1100px breakpoint.** Source: `decision-ui.css:38,42,203–204`. At 1101px the companion jumps from 290 to 340px while the player pool jumps from one card to two. Even before outer stage insets, each card has at most `(1101 − 340 − 20 − 40 − 16)/2 = 342.5px`; with 3vw stage insets it is roughly 309px. This combines a fixed 58px rating, 14px identity gap, and 32px inner padding with 19px names and multiple role labels. Fix: keep one card column until the pool itself is ≥680–720px, using a pool container query or `repeat(auto-fit,minmax(min(100%,320px),1fr))`. Reduce the companion only if its own typography remains intact. Source-derived pressure point, not measured rendering.

2. **Mobile draft spends ~253px on filters before the first player.** Source: `.gccuiFilters`, `.gccuiFilters label`, controls and the ≤760px rule. Three stacked controls cost `3 × (16.8px label + 7px gap + 44px control) + 24px grid gaps + 32px padding + border ≈260px`. This is avoidable vertical bulk on the primary repeat decision screen. Fix: search spans both columns; Role and Sort share a second row, each with `minmax(0,1fr)`. Retain 44px control height and 12px labels. At ≤360px allow the labels to wrap but keep the fields paired where possible. Source arithmetic only.

3. **XI rows reserve nearly a full screen just for the batting list.** Source: `.gccuiOrderRow` and `.gccuiBenchRow`, `decision-ui.css:92,103`: both impose 90px minimum height. Eleven batters alone therefore require ≥990px, before headings and controls. For desktop rows with only name, role and no pulse, this is substantially looser than the stats/table rhythm. Fix: desktop base 68–72px, padding `10px 12px`, retaining automatic growth when injury/morale chips exist. Preserve the existing action-wrap layout ≤1100px, where 90px may still be needed; do not force a smaller fixed height on wrapped mobile rows. Source-only density defect; confirm against Build 33 capture before modifying.

4. **The draft companion is physically placed after the entire player pool on mobile.** Source: `.gccuiDraftGrid` stacking and `.gccuiCompanion{order:2}` at ≤760px. `poolBoard()` can render many candidates and Show more. The coverage and picked-team feedback are consequently below the long selection task. Fix: keep the full companion there, but add a compact readout directly below the turn strip (picked count + batting/bowling coverage + projected XI), with a button opening/scrolling to the full squad. Do not move the full large companion above candidates. This is document-order evidence, not a claimed screenshot observation.

5. **Offseason returning-development columns can be too narrow just above 900px.** Source: `decision-ui.css:667–673`; `.g8development` switches directly from 1 to 3 columns. At 901px with 3vw stage margins, panel borders/padding and 36px gaps, each column is about 256px. The development identity shares that width with a nonshrinking 20px overall transition; skill rows also hold label, delta and before→after values. Fix: use 2 columns for 901–1199px, 3 above 1200px, one below 760px; preferably use a 290px minimum-card container rule. The older Build 32 raster shows the three-column arrangement at 1135px but does not establish overflow at 901px. Source-derived risk requiring capture validation.

Stats: no defensible new geometry defect from source alone. Seven-column season records intentionally use horizontal table scrolling; latest CSS gives leader/finals tables fixed mobile column proportions. Do not replace these with cards without a concrete captured failure. Current ladder identity alignment is explicitly corrected at lines 655–657.
