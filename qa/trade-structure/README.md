# Structural pick-trade tests

`probe.json` is retained pre-fix evidence: one paired actual annual draft, same source save and user recruitment policy, with/without the strongest legal immediate-overall pick-assisted upgrade found. Its actual CPU roster lost17 total overall points without compensating draft improvement. Do not rerun `probe.mjs` on the fixed build and overwrite that historical observation.

`pick-value-test.mjs` reproduces and rejects the same package on the final build, checks no player/pick transfer, private-future independence and zero credit for invalid rounds, empty pools and nonexistent full-list selections. `fair-package.mjs` finds and executes a genuinely useful pick-assisted package, checks positive marginal credit, and rejects reuse after transfer. These are bounded cases, not exhaustive proof of trade balance.

`native.cjs` performs both reviews/confirmations with visible browser input selection at390px and checks the result, ownership and review contrast. Requires Playwright and Chromium; change its executable path to your local runtime. It uses the actual completed2008 fixture in `qa/stabilisation/fixtures/foundation.json`. Other tests also use the generated actual completed2010 checkpoint from the structural career run, as documented in `qa/structural-risk/README.md`.

The valuation is a public estimate of additional list improvement: actual pick queue position, eligible pool, receiving club's own selections and replaceable retained players. It does not inspect private future outcomes, promise a specific player, create nonexistent picks or bypass keeper/bowling safeguards.
